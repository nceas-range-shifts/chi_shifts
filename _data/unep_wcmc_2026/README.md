# `_data/unep_wcmc_2026/` — WDPA/WDOECM Marine Protected Areas

## Script
`data_mgmt/data_access_mpas.qmd`

## Contents
- `wdpa_wdoecm_july2026.gpkg` — combined WDPA + WDOECM polygon layer (all marine PAs and OECMs, July 2026)
- `wdpa_wdoecm_mpas_july2026.tif` — 0.05° raster of MPA IUCN protection category (minimum per cell)
- `wdpa_wdoecm_oecms_july2026.tif` — 0.05° raster of OECM IUCN category (minimum per cell)
- `WDPA_sources_Jul2026.csv` — data sources table included in the WDPA download
- Language-specific resource folders (Arabic, English, French, Russian, Spanish) — included in the original WDPA download package
