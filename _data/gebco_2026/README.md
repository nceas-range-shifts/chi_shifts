# `_data/gebco_2026/` — GEBCO 2026 Global Bathymetry

## Script
`data_mgmt/data_access_bathymetry.qmd`

> **Note:** This script is titled "Download data for fisheries from FAO and ISIMIP" but also handles GEBCO. Consider renaming or splitting the script.

## Contents
- `GEBCO_2026_sub_ice_0.05.nc` — GEBCO 2026 sub-ice topo/bathymetry aggregated to 0.05° resolution
- `GEBCO_Grid_documentation.pdf` — GEBCO documentation
- `GEBCO_Grid_terms_of_use.pdf` — GEBCO terms of use

Original 15-arcsecond (~0.00417°) NetCDF was downloaded and aggregated (factor 12) to 0.05° to match the project grid.

## Source / URL
- Product page: https://www.gebco.net/data-products/gridded-bathymetry-data#global
- Download: https://dap.ceda.ac.uk/bodc/gebco/global/gebco_2026/sub_ice_topography_bathymetry/netcdf/GEBCO_2026_sub_ice.zip?download=1
