# `_data/isimip_2026/` — ISIMIP3b Marine Fishery Projections

## Script
`data_mgmt/data_access_fisheries.qmd`

## Contents
- `filelist.txt` — list of source URLs for all downloaded NetCDF files
- `rasts/` — downloaded ISIMIP3b EcoOcean NetCDF rasters

Files are EcoOcean model outputs under the GFDL-ESM4 / SSP5-8.5 scenario (2015–2100), covering benthic and pelagic consumer biomass at multiple size classes and total consumer biomass.

## Source / URL
https://data.isimip.org/search/tree/ISIMIP3b

Files are downloaded from `https://files.isimip.org/ISIMIP3b/OutputData/marine-fishery_global/EcoOcean/gfdl-esm4/future/` — see `filelist.txt` for the full list of URLs.
