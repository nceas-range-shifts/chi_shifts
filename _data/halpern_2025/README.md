# `_data/halpern_2025/` — Halpern et al. 2025 Stressor and Impact Data

## Script
`data_mgmt/data_access_stressors.qmd`

## Contents
- `habitat_maps/` — habitat type rasters
- `pressures_raw/` — raw (unrescaled) stressor/pressure rasters
- `pressures_rescaled/` — rescaled stressor/pressure rasters (0–1)
- `impacts_by_pressure/` — habitat-weighted impact rasters per pressure
- `impacts_by_pressure_reprojected/` — select reprojected layers (Mollweide → 0.05° WGS 84)
- `cumulative_impact/` — cumulative human impact rasters
