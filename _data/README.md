# `_data/` — Data Directory

All raw and processed data for the `chi_shifts` project live here.
Most files are excluded from version control via `.gitignore` and must be regenerated by running the relevant `data_mgmt/` script.

## Subdirectories

| Directory | Description | Script |
|---|---|---|
| `eezs/` | EEZ and UN M49 georegion rasters | `data_mgmt/data_access_eezs.qmd` |
| `fao_2026/` | FAO capture and aquaculture statistics | `data_mgmt/data_access_fisheries.qmd` |
| `gebco_2026/` | GEBCO 2026 global bathymetry | `data_mgmt/data_access_bathymetry.qmd` |
| `halpern_2025/` | Halpern et al. 2025 stressor, habitat, and cumulative impact rasters | `data_mgmt/data_access_stressors.qmd` |
| `isimip_2026/` | ISIMIP3b EcoOcean marine fishery projections | `data_mgmt/data_access_fisheries.qmd` |
| `iucn_redlist_2026/` | IUCN Red List assessments and WoRMS/AphiaID crosswalks | `data_mgmt/data_access_iucn.qmd` |
| `ohara_2024/` | Species vulnerability traits/scores and functional entity traits | `data_mgmt/data_access_vuln_traits.qmd`, `data_mgmt/data_access_funct_entities.qmd` |
| `unep_wcmc_2026/` | WDPA/WDOECM marine protected area polygons and rasters | `data_mgmt/data_access_mpas.qmd` |

> **Note:** AquaX SDM source data lives outside this repo at `/home/shares/data-aquax/` (read-only shared server). Thermal niche processing is handled by `data_mgmt/data_access_aquax_thermal_niche.qmd`.
