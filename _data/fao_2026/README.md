# `_data/fao_2026/` — FAO Fisheries Statistics

## Script
`data_mgmt/data_access_fisheries.qmd`

## Contents
- `capture/` — FAO global capture fisheries quantity data (CSV)
- `aquaculture/` — FAO global aquaculture quantity data (CSV)
- `fao_capture_spp_genus_fam.csv` — species/genus/family lookup for FAO capture data
- `fao_spp_aphiaid.csv` — FAO species names matched to WoRMS AphiaIDs
- `tuna/` — FAO Global Tuna Atlas

## Source / URL
- Capture fisheries: https://www.fao.org/fishery/collection/capture/en
  - Direct download: `https://www.fao.org/fishery/static/Data/Capture_2026.1.0.zip`
- Aquaculture: https://www.fao.org/fishery/collection/aquaculture/en
  - Direct download: `https://www.fao.org/fishery/static/Data/Aquaculture_2026.1.0.zip`

## Citation

* FAO. 2026. Global Production 1950–2024. In: FAO Fisheries and Aquaculture Division [online]. Rome.
